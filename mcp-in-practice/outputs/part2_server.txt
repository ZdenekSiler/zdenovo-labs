== 1. three independent read-only layers, each tested alone ==
plain connection (no protection)         write SUCCEEDED (rolled back)
layer 1: mode=ro                         OperationalError: attempt to write a readonly database
layer 2: PRAGMA query_only (rw file)     OperationalError: attempt to write a readonly database
layer 3: authorizer                      UPDATE posts SET views = views + 1  -> refused by policy: update
layer 3: authorizer                      SELECT author, body FROM comments   -> refused by policy: read comments.author
layer 3: authorizer                      ATTACH DATABASE '/tmp/x.db' AS x    -> refused by policy: attach
layer 3: authorizer                      SELECT load_extension('evil')       -> refused by policy: function load_extension
